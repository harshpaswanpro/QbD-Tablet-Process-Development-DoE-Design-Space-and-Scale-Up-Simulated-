# QbD-Tablet-Process-Development-DoE-Design-Space-and-Scale-Up-Simulated-
An end-to-end Quality by Design (QbD) workflow for a hypothetical 100 mg immediate-release tablet made by wet granulation, built in Python: risk assessment (FMEA) → Box-Behnken DoE → response-surface models → Monte Carlo design space → confirmatory batches → scale-up plan and control strategy.
